# Сайт Лимон Медиа — описание проекта

## Что это

Маркетинговый сайт студии **Лимон Медиа** — дизайн-студия полного цикла. Сайт нужен для:

1. Привлечения новых клиентов через рекламу/SEO/прямой трафик
2. Демонстрации кейсов и команды
3. Конверсии посетителей в заявку на демо
4. Прозрачного донесения тарифов и условий

## Аналог и референс

Структура и набор страниц вдохновлены международной платформой **[feedbird.com](https://feedbird.com/)** — сервисом контента для соцсетей. Из их каркаса взято:

- Логика страниц (Главная → Прайс → Демо → Кейсы → Отзывы → О нас)
- Подача через крупные карточки и FAQ
- Идея «единого окна» и фиксированной подписки

**Тексты, дизайн, ассеты — оригинальные**, написаны под русский рынок и реальную деятельность Лимон Медиа.

## Визуальный стиль

Жёлто-чёрная палитра в духе утилитарной типографики (отсылка к стилю T-Bank — крупный жёлтый акцент, чёрная типографика, скруглённые карточки):

- Основной жёлтый: `#FFDD2D`
- Чёрный текст: `#1B1B1B`
- Серые тона (нейтральные)
- Шрифт: Manrope (Google Fonts) — отличная кириллица

Полная спецификация — в [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md).

## Технологии

| Что | Решение |

## Архитектурные решения

### Почему не Next.js / Astro

19 страниц планируется в проекте, ядро — 6. Для лендинга со статичным контентом фреймворк — оверкилл: сложнее деплой, выше latency, больше точек отказа. Чистая статика:

- Загружается мгновенно (нет JS-runtime)
- Не зависит от сборки и Node-версии
- Можно править прямо на VPS, если приспичит
- Идеально кэшируется

### Почему inline header/footer (а не include)

Без сборщика подключать partials можно либо через JS-fetch (медленно, плохо для SEO), либо через серверный SSI (require nginx setup). Решение: дублировать шапку/подвал в каждой странице. Когда правок будет много — добавим простой Node-скрипт для инжекта.

### Адаптив

Брейкпоинты: 480 / 768 / 1024 / 1280. Подход — mobile-first в духе «бургер на 768, остальное масштабируется через clamp». Все цены, заголовки, отступы используют `clamp()` для плавного масштабирования.

## Деплой

Один скрипт: `./deploy/deploy.sh` — rsync + nginx reload. Подробнее — [`DEPLOY.md`](./DEPLOY.md).

## Известные ограничения

- **Форма демо** — пока без бэкенда: при сабмите показывает success-сообщение, но никуда не отправляет. Подключить можно к любому email-сервису (например, formspree.io или собственный php-обработчик).
- **HTTPS** — пока только HTTP (нет домена для Let's Encrypt). Если прикрутить домен — добавим `certbot --nginx` за 5 минут.
- **SEO-микроразметка** — базовый Open Graph есть, но Schema.org JSON-LD пока не добавлен.
