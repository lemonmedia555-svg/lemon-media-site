# Карта страниц прототипа

Актуальная версия: 05.08.2026. Старая структура с демо-звонком, видео, рекламой и неподтверждёнными метриками отменена.

## Основной путь клиента

| Страница | Роль |
|---|---|
| `index.html` | Главная воронка контент-подписки |
| `pricing.html` | Тарифы и интерактивный конструктор |
| `examples.html` | Каталог реальных работ |
| `case.html` | Подробный кейс DEVOTEX |
| `case-johnny.html` | Подробный кейс «Джонни Тунец» |
| `process.html` | Первый месяц, роли, сроки и границы |
| `compare.html` | Сравнение с самостоятельной работой, ИИ, фрилансером, штатом и агентством |
| `reviews.html` | Проверяемая репутация Lemon Media и будущие SMM-отзывы |
| `guarantee.html` | Проект точных условий первой партии |
| `faq.html` | Полный справочный центр |
| `start.html` | Состав заказа и заявка до подключения оплаты |

## Дополнительные маршруты

| Страница | Роль |
|---|---|
| `audit.html` | Бесплатный разбор социальных сетей маркетологом |
| `services.html` | Разовые услуги: бренд-система, AI-аватар, оформление соцсетей |
| `partners.html` | Отдельная white-label ветка для маркетологов и агентств |
| `about.html` | Компания, система и принципы |
| `articles.html` | Будущий экспертный и SEO-раздел |
| `404.html` | Актуальная страница ошибки |
| `book-demo.html` | Совместимость со старой ссылкой: перенаправление на `start.html` |
| `legal.html` | Честный статус оферты, политики и условий возврата до утверждения документов |

Подробная логика, доказательства и ограничения находятся в `MARKETING_PROTOTYPE.md` и `MARKETING_LOGIC_11.md`.
