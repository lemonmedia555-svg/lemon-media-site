# Шаблон внутренних страниц lemonmedia

Обновлено: 10.08.2026  
Статус: обязательный стандарт для всех внутренних страниц сайта.

## 1. Источники

- Главная и общий визуальный язык: `top-three-air-study.html`.
- Страница работ: `examples-study.html`.
- Кейсы: `case-saratov-kitchens-design.html` и `CASE_TEMPLATE.md`.
- Тексты и логика: одноимённый файл прототипа без суффикса. Прототип только читаем.
- Общий визуальный слой внутренних страниц: `assets/design/site-page-template.css`.
- Точные дизайн-маршруты: `content/site-design-index.yml`.

## 2. Неподвижный каркас

- Шрифт только Manrope.
- Главный контейнер `1328px`.
- Боковые поля крупных блоков: `28px` на компьютере, `8px` на планшете, `6px` на телефоне.
- Меню, CTA и футер имеют одинаковую ширину с первым экраном.
- Меню — белая капсула высотой не меньше `64px`.
- Основная кнопка — жёлтая, с чёрным текстом.
- Первый экран и большие цветовые поля имеют радиус `46px` на компьютере.
- Карточки имеют радиус `30px`, тонкую линию и почти не используют тень.
- Финальный CTA соединяется с футером без случайной полосы.

## 3. Типографика

| Роль | Размер |
|---|---|
| H1 | `42–66px`, вес 800 |
| H2 | `36–60px`, вес 800 |
| H3 | `24–30px`, вес 800 |
| Лид | `20px` |
| Основной текст | `18px` |
| Интерфейс | `14–17px` |

Одинаковые роли всегда используют одну шкалу. Декоративные уточнения перед заголовками скрыты. Секция начинается сразу с H1, H2 или H3.

Заголовок финального CTA равен H2. Он не должен быть крупнее главного H1; предложение выделяется цветом и композицией.

## 4. Воздух и композиция

- Обычная секция: примерно `124px` сверху и снизу.
- Между карточками: `20px`.
- В одном блоке один главный смысл и один уровень внимания.
- Не каждая секция становится цветной карточкой. Белые редакционные паузы обязательны.
- Допустимы разные композиции: таблица, этапы, калькулятор, витрина, форма, редакционная сетка, тёмное поле.
- Структура разделов сохраняется из прототипа, но визуальная подача подчиняется единой сетке.

## 5. Темы страниц

- Цены и услуги: мягкий фиолетовый первый экран.
- Процесс и аудит: мягкий лимонный первый экран.
- Отзывы, статьи и материалы: холодный лавандовый первый экран.
- FAQ и документы: спокойный холодный первый экран.
- Сравнение, гарантия, партнёры и компания: тёмный первый экран.
- Старт: фирменный тёмный градиент.

Тема меняет характер первого экрана, но не меняет меню, сетку, шрифты, кнопки и футер.

## 6. Компоненты

- Карточка: белая поверхность, линия `1px`, радиус `30px`, внутреннее поле `34px`.
- Форма: поле высотой от `54px`, радиус `16px`, фиолетовый focus.
- FAQ: один спокойный белый блок с крупными строками.
- Таблица: белая поверхность, радиус `30px`, выделение lemonmedia мягким лимонным фоном.
- Этапы: отдельные горизонтальные карточки, номер фиолетовый, срок справа.
- Медиа: не растягивать; пост `4:5`, сторис `9:16`.

## 7. Ссылки и производство

- Прототипы не редактируются и не используются как публичные маршруты из дизайн-страниц.
- Новая версия создаётся скриптом `scripts/generate_site_designs.py`.
- После изменения общего шаблона скрипт запускается повторно: ручные расхождения между внутренними страницами не допускаются.
- Исключение по имени: прототип `article-text-before-design.html` создаёт дизайн-страницу `article-text-before-design-study.html`, чтобы не перезаписать источник.
- Старая ссылка `book-demo.html` ведёт на `start-design.html`.

## 8. Запрещено

- менять прототип ради визуальной правки;
- придумывать отдельный размер заголовка для одной страницы;
- использовать декоративные надзаголовки;
- писать «контент-месяц»;
- растягивать изображения;
- делать каждую секцию фиолетовой, жёлтой или тёмной;
- добавлять случайные линии, полосы, круги и градиенты;
- отделять CTA от футера пустой полосой.
