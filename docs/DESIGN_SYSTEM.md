# Дизайн-система — где она живёт

Этот файл больше не описывает правила. Он указывает на единственный источник, чтобы правды не было две.

## Источник правды

**Пакет:** `lemonmedia. SaaS/06 Маркетинг lemonmedia/Бренд/design-system/`

| Файл | Что внутри |
|---|---|
| `DESIGN.md` | правила словами: логотип, цвет, типографика, геометрия, атмосфера, движение, компоненты, Ксюша, тексты, QA-гейт |
| `tokens.css` | все значения для веба, переменные `--lm-*` |
| `tokens.json` | те же значения вне CSS (Figma, картинки, слайды) |
| `components.css` | базовые компоненты: `lm-btn--*`, `lm-card--*`, `lm-badge--*` |
| `sections.css` | секции-мастера `lms-*` для лендингов |
| `specimen.html`, `site-specimen.html` | витрина системы и образец сборки страницы |

**Канон в Figma:** «LM • SMM DESIGN SYSTEM — v1» — https://www.figma.com/design/W5OADlZzEMJGmjxnpNsIjl

В Claude Code пакет подтягивается скиллом `/lm-design` — он обязывает прочитать `DESIGN.md` и `tokens.css` перед любой визуальной задачей.

## Что лежит в этом репозитории

`assets/css/tokens.css`, `assets/css/components.css`, `assets/css/sections.css` — **копии** пакета. Правим их только в пакете, сюда копируем. Обратного пути нет: правка в репозитории, не внесённая в пакет, будет потеряна при следующей синхронизации.

## Как подключено

`main.css` (страницы about, examples, pricing, reviews, book-demo, 404) импортирует `tokens.css` и держит старые имена переменных (`--yellow`, `--ink`, `--gray-*`, `--sp-*`) алиасами на `--lm-*`. Вёрстка не переписывалась — поменялись только значения.

**Новую вёрстку писать сразу на `var(--lm-*)`.** Алиасы — временный мост для старых страниц, а не слой системы.

### Что изменилось при переходе на канон

| Переменная | Было | Стало |
|---|---|---|
| `--yellow` | `#FFDD2D` | `#EECB03` (единственный жёлтый бренда) |
| `--ink` | `#1B1B1B` | `#020202` |
| `--fs-body` | `16px` | `18px` |
| `--container-max` | `1240px` | `1328px` |

`--r-xs`, `--r-xl`, `--lh-snug`, `--lh-normal`, `--t-fast/base/slow` остались локальными: в каноне их пока нет.

### Ещё не переведено

`assets/css/home.css` (главная) живёт на собственных токенах — `--lemon: #FFCC00`, `--cta: #EECB03`, холодный фон `#EEF3F9`. Перевод отложен: на файле идёт незавершённая работа.
