# Скелет страницы «Примеры работ»

Статус: черновик на утверждение. Этап 2 из [PLAN_MVP.md](../PLAN_MVP.md).
Роль страницы: человек ищет «а как будет выглядеть у меня». Страница должна за минуту показать масштаб и довести до похожего проекта. Строится под рост: на старте ~10-15 карточек-кейсов, дальше 50+; фильтры и подгрузка с первого дня.

Источник данных: `content/cases/*/case.yml` - 34 проекта с нишей, задачей, объёмами и честным результатом.

## Блок 2. Карточки проектов

Сетка карточек, показ частями по 9-12 с кнопкой [Показать ещё] (или автоподгрузка).

**Карточка проекта:**
- 3-6 превью работ (пост 4:5, карусель со счётчиком слайдов, сторис 9:16 - листаются внутри карточки, как в утверждённой ленте)
- Название клиента + город
- Ниша (бейдж)
- Состав одной строкой: «10 публикаций · 3 карусели · 29 визуалов»
- [Открыть проект] → страница кейса

**Порядок карточек:** первым - «Саратов Кухни» (полный месяц), дальше по силе материала и разнообразию ниш; соседние карточки - из разных ниш.

**Н:** реальные работы из content/cases.
