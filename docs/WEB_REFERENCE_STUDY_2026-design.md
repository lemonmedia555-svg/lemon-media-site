# Визуальный разбор референсов для нового сайта lemonmedia

Статус: рабочее исследование, не утвержденный стандарт.

Дата: 23 августа 2026.

Основные источники: [Битрикс24](https://www.bitrix24.ru/), [Postmypost](https://postmypost.io/), [Альфа-Банк](https://alfabank.ru/).

## Что изучено

Исследование сделано по полным визуальным снимкам страниц - от меню до футера. Код сайтов не использовался как источник дизайнерских выводов.

## Битрикс24 - чему учиться

### Композиция

- Первый экран держится на одном крупном обещании, одном действии и одном большом доказательстве продукта.
- Реальный интерфейс занимает заметную часть экрана и работает сильнее декоративной графики.
- Большие главы отделены воздухом. Между ними нет ощущения бесконечной стены одинаковых карточек.
- Ритм постоянно меняется: крупный экран, широкий продуктовый блок, три опоры, интерфейс, отзывы, FAQ.
- Светлые холодные подложки собирают сложные блоки в отдельные «комнаты».

### Продажа

- Сначала объясняется результат для клиента, затем функция.
- Один и тот же продукт показывается несколько раз, но каждый раз с новым сценарием использования.
- В тарифах сначала виден выбор, после него - подробное сравнение.
- Рекомендуемый тариф выделен местом, рамкой и смыслом, а не лишним декором.

### Не копировать

- Повторяющиеся продуктовые блоки без смены масштаба.
- Слишком длинные страницы, если следующий блок не добавляет нового доказательства.
- Иллюстрации, которые красивы, но не показывают работу сервиса.

## Postmypost - чему учиться

### Композиция

- Много белого воздуха и короткие заголовки создают ощущение дорогого спокойного продукта.
- Блоки собраны как крупное асимметричное бенто: один главный модуль и несколько поддерживающих.
- Внутри карточки всегда один тезис и один визуальный объект.
- Темная глава про AI создает сильную паузу и возвращает внимание.
- Интерфейс не помещен в случайный ноутбук: он сам становится главным визуалом.

### Продажа

- Каждая возможность объясняется через рабочую ситуацию пользователя.
- Тарифы показаны сразу, без длинного прогрева перед ценой.
- После короткого выбора идет подробная таблица для тех, кто хочет проверить детали.
- Большой темный футер завершает страницу как самостоятельная глава.

### Не копировать

- Одинаковые пастельные карточки много экранов подряд.
- Слишком мягкую и нейтральную подачу: lemonmedia нужна большая эмоциональная яркость.
- Пустые декоративные пространства, если в них нет работы или продукта.

## Альфа-Банк - чему учиться

### Композиция

- На главной много разных предложений, но каждое живет в отдельной крупной цветной сцене.
- Каталоги собраны плотнее лендингов: изображение, ключевые условия и действие читаются в одной строке или карточке.
- Страница продукта быстро переводит человека от обещания к параметрам, затем к форме.
- Форма не выглядит техническим хвостом. Это одна из главных сцен страницы.
- После формы идут спокойные доказательства, условия, вопросы и большой темный футер.
- Цвет используется крупными пятнами, а не россыпью мелких акцентов.

### Продажа

- Выбор сокращается постепенно: категория, продукт, параметры, заявка.
- У действия всегда понятный ближайший результат.
- Условия находятся рядом с кнопкой, а не спрятаны далеко ниже.
- Длинная обязательная информация визуально отделена от продающей части.

### Не копировать

- Баннерную плотность главной страницы.
- Слишком много равносильных предложений в одном экране.
- Длинные юридические хвосты как часть основной композиции.

## Общие правила нового дизайна lemonmedia

1. Один экран - один главный смысл. Заголовок, доказательство и действие не должны спорить между собой.
2. Показывать реальную работу. Скриншот плана, лента, карусель, сторис, календарь и отзыв сильнее абстрактной иллюстрации.
3. Менять композиционный ритм каждые 1-2 блока: широкий экран, асимметричный сплит, визуальная витрина, компактная таблица, темная глава.
4. Не превращать все в карточки. Карточки нужны для сравнения равных объектов. История, гарантия и главный тезис могут жить свободно.
5. Оставлять крупные чистые зоны вокруг заголовков и ключевого визуала.
6. Желтый использовать для главного действия и смыслового удара. Фиолетовый - для второй линии внимания и отдельных глав.
7. На одном экране только одна главная желтая кнопка.
8. Меню должно вести только к реально существующим страницам и важным участкам главной.
9. Кейс открывается из конкретной карточки работы. В глобальном меню отдельный пункт «Кейс» не нужен.
10. Футер повторяет реальную архитектуру пяти страниц и услуг, а не старую структуру сайта.
11. Цены показываются сразу и крупно. Подробности идут после выбора.
12. Страница работ должна быть визуально плотнее главной: человек пришел смотреть, а не читать вступление.
13. Кейс должен ощущаться как редакционная история проекта, а не как еще один лендинг агентства.
14. Бесплатный разбор должен выглядеть как полезный мини-продукт с понятным результатом, примером и короткой формой.
15. Все цвета, шрифт, радиусы, тени и отступы берутся только из канонической бренд-системы lemonmedia.

## Архитектура пяти страниц

- Главная: обещание → площадки → процесс → полный месяц → ниши → тарифы → гарантия → сравнение → отзывы → FAQ → форма.
- Цены: заголовок → ведение → ролики → разовые услуги → неделя запуска → гарантия → форма.
- Примеры: заголовок и фильтры → каталог работ → запрос своей ниши → форма.
- Кейс: обложка → метрики → логика → работы → контент-план → форматы → честный результат → форма.
- Бесплатный разбор: обещание → состав разбора → настоящий пример → зачем бесплатно → форма.

## Карта переходов

- Логотип → главная.
- Работы → страница примеров.
- Как работаем → блок процесса на главной.
- Цены → страница цен.
- Бесплатный разбор → страница разбора.
- Начать работу / выбрать тариф → форма на странице цен или финальная форма текущей страницы.
- Карточка проекта → конкретный кейс.
- «Посмотреть весь месяц» → контент-план внутри кейса.
- Отправка формы → состояние «заявка отправлена».
- Ошибка поля → состояние с поясняющим текстом, не только красной рамкой.
