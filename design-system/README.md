# Дизайн-система lemonmedia

Канон. Единственный физический источник для всех носителей: сайт, кабинет, SMM-контент, КП и документы.

## Как устроено

| Файл | Что это | Правится руками |
|---|---|---|
| **`system.json`** | **единственный источник правды**: значения, правила, запреты, обоснования, открытые вопросы | **да** |
| `tokens.css` | рантайм-артефакт, его подключают 73 страницы сайта | да, значения обязаны совпадать с system.json |
| `components.css`, `sections.css` | готовые компоненты и секции-мастера | да |
| `specimen.html` | **витрина**: живой пример, как пользоваться, что нельзя и почему | нет, собирается |
| `DESIGN.md` | текстовая версия витрины для чтения и для машин | нет, собирается |
| `tokens.json` | только значения, для инструментов | нет, собирается |
| `REFERENCES.md`, `WEB_ART_DIRECTION.md` | механика страниц-референсов и визуальное направление | да |

## Витрина

Открыть `specimen.html` в браузере из этой папки. Она подключает `tokens.css` напрямую, поэтому всегда показывает текущее состояние системы.

Каждый раздел устроен одинаково: живой пример, «Как пользоваться», «Нельзя», «Почему так», источник. Внизу — открытые вопросы, где система пока не даёт однозначного ответа.

Для машин в конце страницы лежит блок `<script type="application/json" id="lm-system">` со всеми правилами в структурированном виде.

## Сборка

```bash
python3 build/build.py
```

Читает `system.json`, пересобирает `specimen.html`, `DESIGN.md` и `tokens.json`, проверяет, что все цвета из системы присутствуют в `tokens.css`.

## Правило приёмки

Изменение канона не считается принятым, пока оно не показано на витрине и не подтверждено глазами. Порядок: правка `system.json` → сборка → открыть `specimen.html` → подтверждение Ивана → синхронизация копий.

## Копии

Копии внутри репозитория сайта (`design-system/` и `assets/design/`) генерируются:

```bash
cd "../../Сайт/lemon-media-site-prototype"
./scripts/sync-design-tokens.sh          # раскатать канон
./scripts/sync-design-tokens.sh --check  # проверить дрейф перед коммитом
```

Править копии бесполезно — затрутся.

**Легаси-страницы:** старые цвета сводить к канону по карте `migration` в `system.json` (все плавающие жёлтые → `#EECB03`, тёмные → `#020202`).
