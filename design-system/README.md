## Как пользоваться

**Новый веб-проект:** подключи `tokens.css` (+ при желании `components.css`), шрифт Manrope 400–800 с Google Fonts. Цвета — только через `var(--lm-*)`.

**Claude в любом проекте:** скилл `/lm-design` (`~/.claude/skills/lm-design/`) сам читает этот пакет. Или вручную: «прочитай DESIGN.md и tokens.css из папки Бренд/design-system и применяй».

**SMM-контент:** не собирается из CSS — только из мастеров Figma (секция v1: 3 поста, 9 слайдов карусели, компоненты). Этот пакет для SMM даёт значения и правила, а не вёрстку.

**Легаси-страницы:** старые цвета сводить к канону по карте `migration` в tokens.json (все «плавающие» жёлтые → `#EECB03` и т.д.).

## Иерархия источников

1. Figma-файл — канон визуала и SMM-мастеров;
2. этот пакет — канон для кода и текстовых правил;
3. всё остальное (старые CSS в проектах) — легаси до миграции.

Меняется канон → правки вносить и в Figma, и сюда, одним заходом.
