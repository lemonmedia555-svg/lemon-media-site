# lemonmedia — маркетинговый прототип

Эта ветка содержит не финальный дизайн, а кликабельную структуру сайта с текстами, логикой продаж и отдельными страницами.

## Что открыть

- `index.html` — главная страница;
- `docs/MARKETING_PROTOTYPE.md` — объяснение всей структуры и список решений до запуска.

На страницах есть жёлтые заметки: они объясняют задачу каждого блока. Кнопка сверху скрывает заметки и показывает страницу глазами клиента.

## Страницы

- главная;
- работы;
- процесс;
- цены и калькулятор;
- отзывы;
- о компании;
- статьи;
- начало работы.

Форма — демонстрационная: она ничего не отправляет и не принимает оплату.

Прототип сделан на чистом HTML, CSS и JavaScript, без сборки.
