# Сайт Лимон Медиа

Маркетинговый сайт студии **Лимон Медиа** — дизайн-студия полного цикла: логотипы, фирменный стиль, соцсети, контент, реклама.

Структура и набор страниц вдохновлены [feedbird.com](https://feedbird.com/) (взято как референс), визуальный стиль — жёлто-чёрная палитра в духе утилитарной типографики (отсылка к стилистике T-Bank). Тексты — авторские, переработаны под русский рынок и реальную деятельность Лимон Медиа.

## Стек

- **Чистый HTML5 / CSS3 / Vanilla JS** — без сборки, без фреймворков.
- **Nginx** — раздача статики.
- **Хостинг**: VPS `5.182.86.152` (Ubuntu 24.04, root).
- **Шрифты**: Manrope (Google Fonts), system fallback.

Никаких node_modules, никаких build-step — открываешь HTML и работает.

## Локальная разработка

Просто открой `index.html` в браузере. Либо подними локальный сервер:

```bash
cd "Сайт Лимон Медиа"
python3 -m http.server 8080
# открой http://localhost:8080
```
