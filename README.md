# lemonmedia — маркетинговый прототип

Кликабельная структура сайта сервиса регулярного контента для бизнеса. Это не финальный дизайн и не работающий сервис: здесь проверяются оффер, порядок аргументов, состав продукта и маршруты покупки.

## Главное

- `index.html` — главная страница;
- `pricing.html` — пакеты и калькулятор;
- `examples.html` — реальные работы и переходы в кейсы;
- `case-saratov-kitchens.html` — полный реальный контент-месяц;
- `articles.html` — полезные материалы для посетителя перед покупкой;
- `start.html` — прототип начала заказа;
- `docs/MARKETING_PROTOTYPE.md` — полная логика сайта и решения до запуска;
- `docs/MARKETING_LOGIC_11.md` — маркетинговая проверка;
- `docs/MARKETING_ARCHITECTURE.md` — смысл, визуал и поведение каждого блока и страницы;
- `docs/SITE_AUDIT.md` — оценка по маркетингу, конкурентам и полноте сайта;
- `docs/EXPERIENCE_AND_MEDIA.md` — план изображений, видео и интерактива;
- `docs/VIDEO_AND_GUIDE_PLAN.md` — сценарии Ксюши и большого видео владельца.
- `docs/ARTICLE_PLAN.md` — карта готовых полезных статей и правила их развития.

Внутренние редакторские заметки сохранены в разметке, но по умолчанию скрыты: страницы открываются глазами клиента.

## Маршруты

Основной продукт: посты, усиление части постов каруселями и интерес к мини-прогревам по 5 сторис. Отдельно вынесены бесплатный разбор, разовые услуги, партнёрский white-label маршрут, сравнение, гарантия, FAQ и юридический статус.

Формы ничего не отправляют и не принимают оплату. У lemonmedia есть собственный кабинет, а календарь на странице пока является его смысловой демонстрацией до добавления утверждённых скриншотов и записи экрана. Раздел статей содержит 11 самостоятельных материалов с реальными примерами.

Прототип сделан на чистом HTML, CSS и JavaScript, без сборки.
